## 🚀 Featured Projects

### 🤖 Local Dual-Pipeline RAG System

A local question-answering and recommendation system powered by **Qwen2.5 7B** through Ollama.

- Combines semantic vector search with **ChromaDB** and structured graph search with **Neo4j**
- Uses a **Flask backend** and a **Spring Boot frontend**
- Imports movie data from the **TMDB API**
- Runs locally with **Docker Compose** and GPU acceleration
- Designed to be adaptable to other datasets through configuration files

**Tech stack:** Python, Flask, Spring Boot, Ollama, Qwen2.5, ChromaDB, Neo4j, Docker Compose

### 📋 Kanban Web Application

A web-based project management application for managing boards, users, and tasks.

- REST backend developed with **Spring Boot 3**
- Dynamic frontend built with **Thymeleaf**
- Containerized development environment with **Docker**
- Automated testing with **JUnit** and **Selenium**

**Tech stack:** Java, Spring Boot, Thymeleaf, REST API, Docker, JUnit, Selenium

### 🚦 Traffic Sign Classification

A Machine Learning project focused on traffic sign image classification.

- Data cleaning, normalization, and train/validation/test preparation
- Comparison of SVM, KNN, tree-based models, random forests, and neural networks
- Hyperparameter tuning and model evaluation
- Error analysis using accuracy and confusion matrices

**Tech stack:** Python, pandas, NumPy, scikit-learn, Matplotlib
